**Goal:** Build `/qa-spec` — the second qa-kit step — which authors a per-target QA spec that **pins an immutable role snapshot** (`spec-roles.json`) copied from the constitution + stamped with its version, applies per-spec overrides + a **run-config** override section (the folded-in `/qa-plan`, R2-Q3), and surfaces a **drift advisory** when its stamped version ≠ the current constitution's. One spec → N runs (R2-Q5).

**Architecture:** `/qa-spec` reuses `detecting-stack-profile` (stack facts) + optionally `ingesting-spec-kit` (seed oracles/criteria from a *feature* spec-kit) and writes `.qa/specs/<target>/{qa-spec.md, spec-roles.json}`. The genuinely-new logic is `spec-snapshot.sh` (pure, dual-engine): copy the constitution's roles into `spec-roles.json`, stamp the constitution version, apply overrides, and diff a stamped version against the current constitution version. Roles are soft while authoring; they freeze at `plan_frozen` (ADR-0020) when a run starts (increment 5 wires that) — this increment authors the snapshot the run will freeze.

## Global Constraints

- **Snapshot = copy, not reference (design decision 6).** `spec-roles.json` is a point-in-time copy + a stamped `constitutionVersion`. A run replays it; it never re-reads the live constitution mid-run.
- **Reuse existing role state.** The source is `.qa/config.json` `personas[]` (`[{id,role,plane∈global|contextual,auth}]`); the canonical snapshot tuple is `id|role|plane` (auth EXCLUDED — matches increment 1's version canonicalization). Never re-run discovery here.
- **Run-config is per-spec overrides of `.qa/config.json` defaults** (drivers/`maxParallel`/`criteriaBudget`/`viewport`), NOT a re-statement — store only the deltas the spec changes. **This is "run-config," not "plan"** (R2 terminology).
- **Deterministic + dual-engine** (`jq`/`python3`, honor `QA_ENGINE`, die-if-neither); no `grep -P`/`perl`/`node`; no attribution; never commit `dist/`.
- **Drift is an advisory, never an auto-migrate** (R2-Q6): a stale stamp prints a warning; it does not rewrite the snapshot.

## Task 1: `spec-snapshot.sh` — copy + stamp + overrides + drift

**Interfaces:**
- `spec-snapshot.sh create <config.json> <.qa/constitution.state.json> <spec-dir> [<overrides.json>]` → reads `personas[]` from `<config.json>`, the current version + roles from `.qa/constitution.state.json` (R3-Q4 pinned sibling file), applies `<overrides.json>` (optional: `{subset:[ids], add:[{id,role,plane}], modify:[{id, role?, plane?}]}`), and writes `<spec-dir>/spec-roles.json` = `{constitutionVersion:<v>, roles:[{id,role,plane}], overrides:<the applied overrides|null>}`. `subset` filters to the listed ids; `modify` patches role/plane on a matching id; `add` appends (die on an add-id colliding an existing id). Deterministic.
- `spec-snapshot.sh drift <spec-roles.json> <current-constitution-version>` → prints `{stale:<bool>, stamped:<v>, current:<v>}`; `stale` = the two versions differ.

- [ ] **Step 1: Write the failing tests** (`tests/spec-snapshot/run.sh`, dual-engine, mirroring `tests/constitution/run.sh`):
  - `create` with no overrides → `spec-roles.json` has the same role ids as `config.json` personas (as `{id,role,plane}`, auth dropped) + the stamped `constitutionVersion`.
  - `create` with `{subset:["admin"]}` → only `admin` in the snapshot.
  - `create` with `{add:[{id:"bot",role:"bot",plane:"global"}]}` → `bot` present; adding an id that already exists → non-zero (die).
  - `create` with `{modify:[{id:"admin",plane:"contextual"}]}` → admin's plane patched, role unchanged.
  - `drift`: stamped == current → `stale:false`; stamped != current → `stale:true` with both values.
  - dual-engine byte-identical `spec-roles.json`.
- [ ] **Step 2:** run → FAIL (script missing).
- [ ] **Step 3: Implement `spec-snapshot.sh`** — jq/py/die header (copy the sibling idiom). `create`: extract `personas` → map to `{id,role,plane}`, apply subset→modify→add in that order, read the constitution version from the state input, write the snapshot object (sorted by id for determinism). `drift`: compare the stamped `constitutionVersion` to the passed current version.
- [ ] **Step 4:** run → `FAIL=0`; `bash -n`.
- [ ] **Step 5: Commit** `feat(qa-kit): spec-snapshot.sh — copy+stamp constitution roles into spec-roles.json (overrides + drift)`
