# Multi-Harness Portability Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Run the `qa-e2e-pilot` QA methodology on Codex, Pi, and opencode as well as Claude Code, from one canonical source, via a shared verbatim core + a small naming/token generator + thin per-harness adapters.

**Architecture:** The 16 skills, 16 bundled scripts, ADRs, and `.qa/` state stay at repo root as the shared core (Claude installs from them directly). A `harness-profiles.json` table + `scripts/build-adapter.sh` generator emit, per harness, an agent manifest and commands into git-ignored `dist/<harness>/`, combining copied core with hand-authored `harnesses/<harness>/` glue. The three repo-root Claude-facing files (`agents/qa-e2e-pilot.md`, `commands/qa-run.md`, `commands/qa-roles.md`) become generated-and-committed artifacts whose byte-for-byte regeneration is the generator's correctness oracle.

**Tech Stack:** POSIX bash + `python3` (JSON/TOML parsing, always present per CLAUDE.md), `node --check` for JS, existing `@playwright/mcp` server. No new runtime deps. No build framework — "tests" are static-validation + smoke scripts (per CLAUDE.md).

## Global Constraints

- Verdicts stay exactly `pass | fail | blocked | deferred | error`; confidence `high | low`; suspected layer `FE | route | service | migration | DB`. No adapter changes these.
- **v1 is sequential-only** — no subagent fan-out is wired on any harness (ADR-0003 default). `fanning-out-criteria` per-harness dispatch is deferred.
- The shared core (skills, scripts, ADRs, `.qa/` model) is **frozen** for this effort — no skill logic, script logic, or ADR is rewritten. Only additive edits: read `sessionLogDir` from config; one clarifying SKILL.md note.
- **Repo-root `skills/`, `agents/qa-e2e-pilot.md`, `commands/*.md` must contain NO `{{tokens}}`** (Claude installs them directly). Token-bearing sources live only under `core/` and `harnesses/<h>/`.
- The adapter's Playwright MCP server key is **`playwright-qa`** on Codex/Pi/opencode (project-local config, never mutating global). Claude keeps the official `playwright` key.
- Secrets never printed. `.qa/` writes only. Commit messages carry NO Claude/Anthropic attribution (project + user rule).
- All new `.json` must pass `python3 -c "import json;json.load(open(f))"`; all new `.sh` must pass `bash -n`; all new `.js` must pass `node --check`.

- [ ] **Step 4: Write minimal implementation — the generator**

```bash
#!/usr/bin/env bash
# scripts/build-adapter.sh <harness> — assemble dist/<harness>/ from core + profile + glue.
set -euo pipefail
H="${1:?usage: build-adapter.sh <claude|codex|pi|opencode>}"
ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
PROFILES="$ROOT/harness-profiles.json"
OUT="$ROOT/dist/$H"

# --- read the profile fields for this harness via python3 (jq-free) ---
read_field() { python3 -c "import json,sys;print(json.load(open('$PROFILES'))['harnesses']['$H']['$1'])"; }
PREFIX="$(read_field toolPrefix)"; SERVER_KEY="$(read_field serverKey)"
GRANT="$(read_field grantStyle)"; MODEL_FIELD="$(read_field modelField)"
TIER_DEFAULT="$(read_field tierDefault)"; TIER_HEAVY="$(read_field tierHeavy)"
DISPATCH="$(read_field dispatch)"; ROLES_DIR="$(read_field globalRolesDir)"

# --- render the browser-tools grant per grantStyle ---
render_browser_tools() {
  local caps; caps="$(python3 -c "import json;print(' '.join(json.load(open('$PROFILES'))['capabilities']))")"
  case "$GRANT" in
    list)  local out=""; for c in $caps; do out="${out:+$out, }${PREFIX}${c}"; done; printf '%s' "$out" ;;
    scope) printf '%s' "" ;;   # server-scoped: handled by mcp_servers in the template
    proxy) printf '%s' "" ;;   # proxy tool 'mcp' already in the template
    glob)  printf '%s' "" ;;   # glob '<server>*' already in the template
  esac
}
BROWSER_TOOLS="$(render_browser_tools)"

# --- render the model-field line (Claude pins; others inherit) ---
if [ -n "$MODEL_FIELD" ]; then MODEL_FIELD_LINE="model: $MODEL_FIELD"$'\n'; else MODEL_FIELD_LINE=""; fi

# --- detokenize a file from stdin using the resolved values ---
render() {
  python3 - "$@" <<'PY'
import sys,os
data=sys.stdin.read()
repl={
 "{{PERSONA_BODY}}":  open(os.environ["PERSONA_BODY_FILE"]).read().rstrip("\n"),
 "{{BROWSER_TOOLS}}": os.environ["BROWSER_TOOLS"],
 "{{MODEL_FIELD_LINE}}": os.environ["MODEL_FIELD_LINE"],
 "{{TIER_DEFAULT}}":  os.environ["TIER_DEFAULT"],
 "{{TIER_HEAVY}}":    os.environ["TIER_HEAVY"],
 "{{DISPATCH}}":      os.environ["DISPATCH"],
 "{{GLOBAL_ROLES_DIR}}": os.environ["ROLES_DIR"],
 "{{SERVER_KEY}}":    os.environ["SERVER_KEY"],
}
for k,v in repl.items(): data=data.replace(k,v)
sys.stdout.write(data)
PY
}
export BROWSER_TOOLS MODEL_FIELD_LINE TIER_DEFAULT TIER_HEAVY DISPATCH ROLES_DIR SERVER_KEY

# --- persona body: detokenize tiers first, into a temp file the manifest render inlines ---
PERSONA_BODY_FILE="$(mktemp)"; export PERSONA_BODY_FILE
TIER_DEFAULT="$TIER_DEFAULT" TIER_HEAVY="$TIER_HEAVY" \
  render < "$ROOT/core/persona-body.md" > "$PERSONA_BODY_FILE"

# --- assemble dist/<h> ---
rm -rf "$OUT"; mkdir -p "$OUT/agent" "$OUT/commands"
# core copied verbatim
cp -R "$ROOT/skills" "$ROOT/scripts" "$ROOT/docs" "$ROOT/CONTEXT.md" "$OUT/" 2>/dev/null || true
cp -R "$ROOT/tools" "$OUT/" 2>/dev/null || true
# agent manifest (extension per harness)
case "$H" in claude|pi|opencode) EXT=md ;; codex) EXT=toml ;; esac
# codex embeds the body in a TOML literal '''...''' string — assert the body has no literal '''
if [ "$H" = codex ] && grep -q "'''" "$ROOT/core/persona-body.md"; then
  echo "ERROR: persona body contains ''' which breaks the codex TOML literal string" >&2; exit 1
fi
render < "$ROOT/harnesses/$H/manifest.tmpl" > "$OUT/agent/qa-e2e-pilot.$EXT"
# commands
render < "$ROOT/core/commands/qa-run.md"   > "$OUT/commands/qa-run.md"
render < "$ROOT/core/commands/qa-roles.md" > "$OUT/commands/qa-roles.md"
# mcp snippet (created in Tasks 4-6; claude has none — uses the official plugin)
[ -f "$ROOT/harnesses/$H/mcp.snippet" ] && cp "$ROOT/harnesses/$H/mcp.snippet" "$OUT/mcp.snippet"

# --- fail if any token survived ---
if grep -rn '{{' "$OUT" ; then echo "ERROR: unrendered token in dist/$H" >&2; exit 1; fi
rm -f "$PERSONA_BODY_FILE"
echo "built dist/$H"
```

> Implementer note: the byte-oracle compares `dist/claude/agent/qa-e2e-pilot.md` to `agents/qa-e2e-pilot.md`. The template's trailing newline handling matters — `PERSONA_BODY` is `.rstrip("\n")`-ed and the template ends with `{{PERSONA_BODY}}\n`, so the output ends in exactly one newline. If the diff shows a trailing-newline delta, align the template's final newline, not the oracle.
